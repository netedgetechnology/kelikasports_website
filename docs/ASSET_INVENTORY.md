No user image work is required to proceed. If you later choose to personalize the website, replace the starter images through the CMS with KELIKA-owned/approved photographs. Suggested replacements include:

- Home hero athlete/action photo, program card photos, facility/court photo, event images, testimonial portraits only if genuine and approved, and final CTA background image.
- Academy hero, program/facility/coach/community images.
- Sports hero architecture image, badminton, football, cricket and future-sport card images.
- Programs hero, kids/youth/performance/adult photos, progression images and CTA background.
- Facilities hero, court, flooring, equipment, lighting, lounge, changing-room and other amenities photos only for amenities that exist.
- Events hero, confirmed event images, gallery images and CTA background.
- About hero, facility, coach and community/team photos.
- Contact hero/facility image and CTA background image.
- Favicon and any separate dark/light/mobile logo variants if approved.

Images will be placed through the CMS media library and section settings. Do not use placeholder statistics, unverified facilities, fictional testimonials, invented event dates, or unconfirmed contact information as live public claims.
